# Appgen - SaaS Software Bootstrap Template

A modern, fully responsive Bootstrap 5 template designed for SaaS, Software, and Web App products. This template features a clean, professional design with smooth animations and a complete set of sections for your landing page.

## Features

- ✨ **Modern Design** - Clean, professional UI with smooth animations
- 📱 **Fully Responsive** - Perfect on all devices (desktop, tablet, mobile)
- 🚀 **Bootstrap 5** - Built with the latest Bootstrap framework
- 🎨 **Custom Styling** - Beautiful custom CSS with modern design patterns
- ⚡ **Fast Performance** - Optimized for speed and performance
- 🎯 **Complete Sections** - Hero, Features, About, Pricing, Testimonials, Contact, Footer

## Sections Included

1. **Navigation** - Fixed top navigation with smooth scroll
2. **Hero Section** - Eye-catching hero with CTA buttons and stats
3. **Features Section** - Showcase your product features
4. **About Section** - Tell your story with animated cards
5. **Pricing Section** - Three-tier pricing plans
6. **Testimonials** - Customer reviews and ratings
7. **CTA Section** - Call-to-action banner
8. **Contact Section** - Working contact form
9. **Footer** - Comprehensive footer with links

## Getting Started

1. Open `index.html` in your web browser
2. That's it! No build process required.

## Customization

### Colors

The primary color scheme can be customized in `assets/css/style.css`:

```css
:root {
    --primary-color: #6366f1;
    --primary-dark: #4f46e5;
    --primary-light: #818cf8;
    /* ... more variables */
}
```

### Content

Simply edit the HTML content in `index.html` to match your brand and messaging.
